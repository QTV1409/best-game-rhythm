Neon Encore is an original anime band rhythm game: the band LUMEN PULSE (Aria on vocals, Kira on guitar, Mika on drums, Sora on bass) plays live on a neon stage while notes fall down four lanes. Hit them with D / F / J / K or by clicking a lane, build your combo, and survive the whole 72-second song — every missed note costs a life, and three misses end the show. The song gets denser from verse to chorus to finale, with a score, combo, lives, accuracy and rank (S/A/B/C) on the results screen, plus a synthesised Web Audio soundtrack, pause (P) and mute (M), and a restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
